# EDMC-RhinoDataExporter

An EDMC plugin that exports the RhinoSpotter plugin's data to csv.  This 
is useful for backing up the data as well as sharing it.

## Installation

* Download the [latestrelease] of EDMC-RhinoDataExporter
* Extract the `.zip` archives that you downloaded into the EDMC `plugins` folder
    * This is accessible via the plugins tab in the EDMC settings window
* Start or restart EDMC to register the plugin
